macOS 개발 장비에서 다음을 확인했다.

- TypeScript 테스트 87개와 Python 테스트 67개 통과, 타입 검사·빌드 통과.
- 실제 Python 자식 프로세스로 준비 상태의 부분 전송·한국어 메시지·시간 초과·종료 후 정리를 검증했다. Windows 전용 프로세스 처리 분기는 모의 응답으로 확인했다.
- `npm run doctor`에서 Node.js 24.13.0, Python 3.8.10, Playwright 설치와 Google Chrome 152 실행을 확인했다. 브라우저는 빈 상태로 실행 후 종료했으며 항공사에는 접속하지 않았다.
