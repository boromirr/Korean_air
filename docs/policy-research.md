# 대한항공 공개 좌석 정보 수집 정책 확인

확인일: 2026-09-07, Asia/Tokyo 기준. 작성 시각: 11:31 JST (02:31 UTC).

이 문서는 공개 원문에서 확인한 운영 조건과 미확인 사항을 기록한다. 실제 좌석 검색, 로그인, 예약, 비공개 API 호출은 수행하지 않았다.

## 확인 결과

공개 검색 진입페이지를 읽을 수 있다는 사실만으로 보너스 좌석 데이터의 반복 수집·재배포 허가가 확인되지는 않았다. 공식 robots.txt에는 검색 진입페이지 허용과 API·보너스 항공편 선택 경로 제한이 함께 있다. 실제 데이터 제공 경로와 사용 허가를 확인할 때까지 실시간 수집 운영은 보류하고, 개발·검증은 명시적인 예시 데이터 또는 사용 허가가 확인된 데이터 공급자로 진행하는 것이 이 조사에 따른 구현 판단이다.

## 공식 robots.txt

출처: [대한항공 robots.txt](https://www.koreanair.com/robots.txt)

- web 읽기 도구에서 68행의 `text/plain` 본문을 확인했다. 도구는 재조회 시 수집 시점을 당일로 표시했지만, 이는 배포 서버에서 성공적으로 직접 가져왔다는 증거를 대신하지 않는다.
- 별도의 단순 HTTP GET 1회는 **403 Forbidden**을 반환했다. 사용자 인증정보 없이 연구 목적을 나타내는 User-Agent만 사용했다. 이 응답 이후 직접 HTTP 재시도, User-Agent 위장, 프록시 교체, 차단 우회를 하지 않았다.
- 본문에 있는 관련 규칙은 다음과 같다. 파일 전체를 복사한 것이 아니며, 경로의 마지막 `/`와 `*`를 원문대로 보존했다.

```text
User-agent: *
Allow: /booking/search
Disallow: /api
Disallow: /booking/calendar-fare
Disallow: /booking/award-wait-request
Disallow: /booking/select-flight/
Disallow: /booking/select-award-flight/
Disallow: /login*
```

위 파일에는 그 밖의 예약·결제·회원정보 등 여러 경로 제한도 있다. 확인한 본문에 `Crawl-delay`나 호출 횟수 상한은 없다. 이는 무제한 수집이나 특정 간격의 호출을 허가했다는 뜻이 아니다. `/booking/search`의 Allow를 `/api` 또는 항공편 선택 경로로 확대해서 적용해서는 안 된다. 현재 실제 보너스 좌석 조회가 어느 경로를 사용하는지는 이 조사에서 확인하지 않았다.

## robots 규칙과 사용 허가는 다르다

[IETF RFC 9309, Section 1](https://www.rfc-editor.org/rfc/rfc9309.html#section-1)은 robots 규칙 자체가 접근 권한 부여 수단이 아니라고 명시한다. robots.txt는 자동화 클라이언트에 대한 경로별 접근 지침이며, 계약상 데이터 이용·재배포 허가나 접근통제 장치의 대체물이 아니다. 공개 페이지, 비로그인 접근, robots Allow 중 어느 하나만으로 본 서비스의 전체 운영 권한이 확인되지는 않는다.

RFC는 robots.txt의 4xx 응답을 처리하는 프로토콜 규칙도 제공하지만, 이번 직접 요청의 403을 근거로 대한항공이 수집을 승인했다고 해석하지 않았다. 서비스의 실제 접근 차단과 이미 확인한 경로 제한을 함께 고려해야 한다. [RFC 9309, Section 2.3.1](https://www.rfc-editor.org/rfc/rfc9309.html#section-2.3.1)

## 확인하지 못한 사항

- 실제 비로그인 보너스 좌석 조회 가능 여부, 조회 화면 주소, 호출 방식, 응답 필드, 잔여석 표시 의미.
- 대한항공의 자동 수집·캐시 보관·카카오톡 알림 제공·재배포에 대한 별도 허가, 제휴 계약, 공개 좌석 API의 존재 및 조건.
- 상업적 운영에 필요한 구체적인 동의 범위와 비영리 서비스에 대한 개별 조항의 적용 판단.
- 실제 수집 서버에서 허용되는 호출량, 업데이트 주기, 차단 조건, 정책 변경 여부.
- 한국어 약관 원문 및 영어 본문과의 정합성.

## 구현에 연결할 운영 조건

이는 조사 결과에 따른 프로젝트 운영 제안이며 대한항공이 승인한 조건이 아니다.

1. 실시간 공급자는 기본 비활성으로 두고, 사용 가능한 데이터 경로와 수집·보관·알림·재배포 범위가 확인된 경우에만 활성화한다.
2. 예시 데이터는 실제 잔여석처럼 표시하거나 실제 좌석 발견 알림으로 발송하지 않는다.
3. 수집을 운영하게 되면 공식 robots.txt와 이용약관을 다시 확인한다. 불허 경로, 403·429, 로그인 요구, CAPTCHA·추가 인증 등 접근 제한을 만나면 중단하고 운영자에게 상태를 표시한다.
4. 대한항공 계정·쿠키·토큰을 수집·공유하여 비로그인 제약을 해소하는 방식을 사용하지 않는다.
5. 허가가 확인되더라도 결과의 확인 시각과 실패·미확인 상태를 사용자에게 표시한다. 빈 결과나 수집 실패를 잔여석 없음으로 변환하지 않는다.

조사 과정에서 쿠키·인증정보·차단 페이지 본문을 파일에 저장하지 않았다. 이 파일에는 공개 URL과 정책 요약만 포함되어 있다.
