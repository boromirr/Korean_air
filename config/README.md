# 공항 선택 목록

`award-routes.json`은 [대한항공 보너스 좌석 조회](https://www.koreanair.com/booking/book-and-manage/award-seat-availability)의 **도착지 → 모든 지역 보기**에서 2026년 9월 7일 비로그인으로 확인한 공개 공항 목록입니다. 8개 지역의 탭을 각각 열어 화면의 공항 코드와 한국어 이름 117개를 저장했습니다. 로그인 정보, 좌석 조회 결과, 항공사 응답 원문은 포함하지 않습니다.

## 데이터의 의미

- `sourceUrl`: 확인한 공식 화면
- `retrievedAt`: 목록을 가져온 시각(시간대 포함)
- `airports`: 화면에 표시된 공항 코드·한국어 이름·지역
- `destinations`: 별도로 확인된 출발지별 연결 정보. 현재는 확인하지 못해 빈 객체입니다.

공식 선택 목록에는 출발지와 같은 공항도 표시됩니다. 따라서 이 목록에 있다는 이유만으로 특정 출발지에서 직항이 운항하거나 마일리지 좌석이 있다고 판단할 수 없습니다. **모든 공항 조합을 노선으로 만들어 저장하지 않습니다.** 로컬 화면은 같은 출발·도착 공항을 제외해 선택을 돕고, 선택한 조건의 공개 좌석 현황은 조회 버튼으로 확인합니다.

## 갱신

앱은 실행할 때 이 파일을 읽습니다. 목록을 여는 것만으로 항공사에 접속하거나 자동으로 목록을 갱신하지 않습니다. 최신 목록이 반영된 프로젝트 버전을 받으면 함께 갱신됩니다.

목록을 수정할 때는 공식 화면의 각 지역 탭을 다시 확인하고 실제로 읽은 공항만 반영한 뒤 `retrievedAt`을 갱신합니다. 특정 출발지의 도착 공항 목록을 독립적으로 확인한 경우에만 `destinations`에 해당 방향을 추가합니다. 역방향 연결을 임의로 추정하지 않습니다.
