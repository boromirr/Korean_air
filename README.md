# 마일리지로 떠나는 날

[![Windows·macOS 자동 검사](https://github.com/we-insub/Korean_air/actions/workflows/test.yml/badge.svg)](https://github.com/we-insub/Korean_air/actions/workflows/test.yml)

대한항공 마일리지 항공권을 찾을 때, **원하는 노선과 좌석 등급에 보너스 좌석 표시가 있는 날짜만 모아보는 개인용 로컬 프로그램**입니다.

조회 결과에서 날짜를 고르면 새 Chrome 창의 대한항공 보너스 좌석 달력에 노선과 날짜를 자동으로 입력해 줍니다. 로그인이나 API 키 없이 공개 조회 화면을 이용합니다.

> 대한항공의 공식 서비스가 아닙니다. 조회 결과는 대한항공이 공개한 기준 시각의 현황이며, 실시간 예약 가능 여부나 정확한 잔여 좌석 수를 뜻하지 않습니다.

## 주요 기능

- 출발·도착 공항, 편도·왕복, 조회할 월, 좌석 등급 선택(전체 포함)
- 대한항공 공식 보너스 조회 화면의 공항 목록에서 도시를 선택하거나 도시명·공항 코드로 검색
- 일반석·프리미엄석·비즈니스(프레스티지석)의 **보너스 좌석** 날짜만 표시
- 왕복의 가는 날·오는 날 선택과 최소 여행 기간에 따른 날짜 필터
- 선택한 조건을 대한항공 공개 달력에 자동 입력
- 이전 조회 결과 저장, 기준 시각 표시, 최근 결과 재사용

좌석 승급 표시는 검색 결과에서 제외합니다. 일등석은 공개 표식에서 보너스와 승급을 구분할 수 없어 현재 지원하지 않습니다.

## 실행 환경

| 항목 | 필요 조건 |
| --- | --- |
| 운영체제 | Windows 11 이상 또는 macOS 14 이상. Linux는 미검증 |
| Python | 3.8 이상, 새로 설치한다면 3.11 이상 권장 |
| Node.js | 22 이상, npm 포함 |
| 브라우저 | Google Chrome 설치 필요 |

Python 패키지, 데이터베이스, `.env` 설정은 필요하지 않습니다. **Node.js용 Playwright는 `npm ci`에 포함되어 설치됩니다.** Google Chrome은 별도로 설치되어 있어야 합니다. 운영체제 기준은 [Playwright의 공식 실행 환경](https://playwright.dev/docs/intro#system-requirements)을 따릅니다.

## 빠른 시작

### 1. 프로젝트 받기

GitHub의 **Code → Download ZIP**으로 내려받아 압축을 풀거나, 이 저장소를 클론합니다. 터미널에서 `package.json`과 `local_app.py`가 있는 프로젝트 폴더로 이동하세요.

### 2. Windows에서 설치하고 실행하기

먼저 [Python](https://www.python.org/downloads/windows/), [Node.js](https://nodejs.org/en/download), [Google Chrome](https://www.google.com/chrome/)을 설치합니다. Python 설치 과정에 **Add python.exe to PATH** 항목이 있으면 선택하세요.

1. 압축을 푼 프로젝트 폴더에서 **`setup-windows.bat`를 더블클릭**합니다.
2. Playwright를 포함한 의존성 설치와 실행 환경 확인이 끝날 때까지 기다립니다.
3. **`start-windows.bat`를 더블클릭**하면 로컬 조회 화면이 열립니다.

다음부터는 `start-windows.bat`만 실행하면 됩니다. 설치된 프로그램을 찾지 못하면 설치를 마친 뒤 실행 창을 새로 열어 주세요.

PowerShell에서 직접 실행하려면 프로젝트 폴더에서 다음 명령을 사용합니다. `python` 대신 `py -3`를 사용해도 됩니다.

```powershell
npm.cmd ci
npm.cmd run doctor
python local_app.py --open
```

### 3. macOS에서 설치하고 실행하기

프로젝트 폴더에서 다음 명령을 실행합니다.

```sh
npm ci
npm run doctor
python3 local_app.py --open
```

브라우저에 [로컬 조회 화면](http://127.0.0.1:8765/)이 열립니다. 자동으로 열리지 않으면 이 주소를 직접 열어 주세요. 사용하는 동안 터미널을 열어 두고, 종료할 때는 터미널에서 `Ctrl+C`를 누릅니다.

다음 실행부터는 `npm ci`를 다시 실행할 필요 없이 아래 명령만 사용하면 됩니다. 의존성이 변경된 버전을 받은 경우에는 `npm ci`를 다시 실행하세요.

```sh
python3 local_app.py --open
```

macOS에서는 최초 설치 후 **`마일리지 조회.command`를 더블클릭**해도 됩니다. 더블클릭 실행이 되지 않으면 위 터미널 명령을 사용하세요.

### 4. 마일리지 좌석 조회하기

1. 출발·도착 공항의 목록 버튼을 눌러 도시를 고릅니다. `인천`, `싱가포르`, `ICN`, `SIN`처럼 도시명이나 공항 코드로 검색해 선택해도 됩니다.
2. 편도·왕복, 조회할 월, 좌석 등급을 선택합니다.
3. **마일리지 좌석 조회**를 누릅니다.
4. 결과에서 원하는 날짜를 고릅니다. 왕복은 가는 날과 오는 날을 모두 선택합니다.
5. **선택한 날짜로 대한항공 열기**를 누르면 새 Chrome 창에 선택한 조건이 자동 입력됩니다.

**처음 설치한 상태에는 저장된 조회 결과가 없습니다.** 화면을 열거나 조건을 바꾸는 것만으로 새 조회가 시작되지는 않으므로, 처음에는 조회 버튼을 눌러 주세요.

도시 목록에는 2026년 9월 7일 대한항공 보너스 조회 화면에서 확인한 **8개 지역·117개 공항**을 미리 담았습니다. 공항 목록에 있다는 것이 특정 노선의 운항이나 좌석을 보장하지는 않습니다. 목록은 프로젝트에 포함되어 있으며, 목록을 열거나 검색할 때 항공사에 접속하지 않습니다. 공항 코드 세 글자를 직접 입력할 수도 있습니다. [목록의 출처와 갱신 방법](config/README.md)

가는 달·오는 달은 **연도별로 구분된 월 목록**에서 선택합니다. 다음 해의 월도 같은 목록에 있으며, 현재 조회 가능한 기간은 입력란 아래에 표시합니다. 왕복의 오는 달은 가는 달보다 앞선 월을 선택할 수 없습니다.

좌석 등급에서 **전체**를 고르면 일반석·프리미엄석·비즈니스 중 하나라도 보너스 좌석 표시가 있는 날짜를 보여줍니다. 날짜 카드에 표시가 있는 등급을 함께 적으며, 같은 날짜는 한 번만 셉니다. 일등석과 좌석 승급 표시는 제외합니다. 기존 조회 결과가 있으면 전체로 바꿔도 그 결과를 그대로 활용합니다.

공항 코드 예시, 왕복 선택, 오류 해결은 **[자세한 사용법](docs/usage.md)**에서 확인할 수 있습니다.

### Playwright도 따로 설치해야 하나요?

`setup-windows.bat` 또는 `npm ci`가 프로젝트에 지정된 Playwright와 실행 도구를 함께 설치합니다. Python용 `pip install playwright`는 필요하지 않습니다.

이 프로그램은 설치된 **Google Chrome**을 사용합니다. 따라서 Chrome을 공식 설치 프로그램으로 준비하면 별도의 `npx playwright install` 과정은 필요하지 않습니다. 환경 확인 명령인 `npm run doctor`는 Chrome을 잠깐 실행해 확인한 뒤 닫으며, 대한항공에는 접속하지 않습니다. [Playwright의 Chrome 사용 안내](https://playwright.dev/docs/browsers#google-chrome--microsoft-edge)

## 두 버튼의 차이

| 버튼 | 동작 |
| --- | --- |
| 마일리지 좌석 조회 | 선택한 노선·월의 공개 현황을 불러옵니다. 최근 12시간 이내 저장 결과가 있으면 재사용합니다. |
| 선택한 날짜로 대한항공 열기 | 버튼을 누를 때 새 Chrome 창을 열고, 공식 공개 달력에 노선·편도/왕복·월·좌석 등급·날짜를 입력합니다. |

자동 입력은 기존 Chrome의 로그인 상태를 가져오지 않는 별도 창에서 진행됩니다. 완료 후 창이 열린 상태로 남으므로 직접 확인할 수 있습니다. 로그인·예약·결제는 자동으로 진행하지 않습니다. 좌석 등급은 **공개 달력의 필터**에 적용되며, 이후 예매 화면까지 같은 조건이 전달되는 기능은 아닙니다.

전체로 조회한 날짜를 열면 대한항공 달력에도 일반석·프리미엄석·프레스티지석의 **보너스 필터 3개**를 적용합니다. 일등석·좌석 승급 필터는 적용하지 않습니다.

## 조회 결과를 읽는 방법

- **좌석 표시가 있는 날짜:** 공개 달력에 선택한 등급의 보너스 좌석 표시가 있는 날짜 수입니다. `0일`이면 공개 현황에 해당 표시가 없다는 뜻이며 조회 실패나 실시간 매진을 뜻하지 않습니다. 확인한 월 전체 날짜 수도 따로 표시합니다.
- **여행 기간에 맞는 날짜:** 왕복의 오는 편에서 선택한 가는 날과 최소 여행 기간에 맞는 날짜 수입니다. 이달의 전체 보너스 표시 날짜 수와 다를 수 있습니다.
- **대한항공 공개 현황 기준:** 대한항공이 공개 현황의 기준으로 표시한 시각입니다.
- **현황을 가져온 시각:** 이 프로그램이 해당 결과를 가져온 시각입니다. 대한항공 공개 현황 기준과 다를 수 있습니다.
- **이번에 가져온 결과 / 이전에 가져온 결과:** 새로 조회한 구간과 저장된 결과를 재사용한 구간을 구분합니다. 조회 버튼을 눌러도 최근 12시간 이내 결과라면 재사용합니다.

조회가 완료되지 않은 구간은 `좌석 현황 미확인`으로 안내합니다. 새 조회에 실패해도 이전에 저장한 결과를 삭제하지 않으며, 이전 결과를 보여주는 경우 별도로 안내합니다.

## 지원 범위

- 이번 달을 제외하고, 대한항공의 향후 360일 범위 안에 **전체 날짜가 포함되는 미래 월**을 조회합니다. 화면에서 선택 가능한 범위를 확인해 주세요.
- 왕복은 가는 편과 오는 편을 각각 조회합니다. 두 날짜에 공개 표식이 있다고 해서 해당 왕복 조합의 예약이 보장되지는 않습니다.
- 화면의 ‘최소 여행 기간’은 **두 항공편의 출발일 간격**입니다. 도착 시각과 시차를 반영한 실제 체류 기간은 아닙니다.
- 모든 목적지·모든 월의 일괄 검색, 정기 알림, 카카오톡·이메일 발송은 제공하지 않습니다.
- 사이트의 화면 구조가 바뀌거나 접속이 제한되면 자동 처리가 중단될 수 있습니다. 접근 제한을 우회하거나 자동으로 재시도하지 않습니다.

프로그램은 `127.0.0.1`에서만 실행됩니다. 이 저장소를 GitHub에 올려도 조회 서비스가 자동으로 배포되지는 않습니다. 데이터 이용 범위는 대한항공의 정책을 확인해야 하며, 로컬 실행이나 비로그인 접근 자체가 이용 허가를 의미하지는 않습니다.

## 저장되는 파일

| 경로 | 용도 |
| --- | --- |
| `data/local/` | 노선·월별 조회 결과와 접근 제한 상태 |
| `artifacts/airline-handoff/` | 자동 입력 실패 시 공개 화면의 제한된 진단 자료 |
| `data/`, `artifacts/` | 별도 CLI 실행 결과와 개발용 검증 자료 |

위 폴더와 `.env`, 인증 세션 파일, 로그, `node_modules/`는 `.gitignore`에 포함되어 있습니다. **조회 데이터는 저장소에 포함되지 않으며**, 다른 컴퓨터에서는 직접 조회해야 합니다. 비밀번호·로그인 쿠키를 저장소에 넣을 필요가 없습니다.

## 개발 및 문서

```sh
npm test
npm run typecheck
npm run build
python3 -m unittest discover -s tests -p 'test_*.py'
```

테스트는 저장된 테스트 자료와 모의 응답을 사용하며 대한항공에 접속하지 않습니다. 일반적인 앱 실행에는 빌드 명령이 필요하지 않습니다.

Windows에서는 위 명령의 `python3`를 `python` 또는 `py -3`로 바꾸세요. PowerShell에서는 `npm.cmd`를 사용하면 npm의 PowerShell 실행 정책 오류를 피할 수 있습니다.

GitHub Actions의 Windows·macOS 환경에서 설치, 자동 테스트, 타입 검사와 빌드가 모두 통과했습니다. Windows에서는 한글 경로의 실행 파일과 하위 프로세스 종료도 확인했습니다. [검사 결과 보기](https://github.com/we-insub/Korean_air/actions/runs/34083177862)

실제 대한항공 조회까지 확인한 환경은 macOS이며, Windows 실기기에서의 항공사 조회는 아직 검증하지 않았습니다. 자동 테스트는 항공사에 접속하지 않습니다.
